# Saíra 7 — Sítio em Sana, Macaé (RJ)

Website e landing page para divulgação e locação de sítio na região de Sana (Cabeceira), Macaé - RJ.

## 🌿 Sobre o Projeto

O objetivo deste projeto é construir uma landing page moderna, atrativa e funcional para:
- **Aluguel por temporada / diária** (estilo Airbnb): hospedagem com contato direto com a natureza da serra.
- **Espaço para eventos**: celebrações, retiros, encontros e confraternizações.

## 📍 Localização
- **Local:** Cabeceira do Sana, Macaé - RJ
